# v0.1.0 — 首个可用版本

自动完成课程直播签到：抓取课堂直播画面里的签到二维码 → 解码 → 纯 HTTP 提交，抢在动态码失效前完成。

## 主要功能

- **自动签到**：按周课表在每节课的监视窗口（课前 5 分钟 → 课后 10 分钟）内工作；平时只是几十 MB 的后台进程，进窗口才启动浏览器。
- **图形控制台**：本周课表 / 全部课程 / 设置三个视图，所有操作走命令总线，不用手改 JSON。
- **首次配置三步**：填学校账号 → 一键发现课程 → 添加到课表。
- **结果可追溯**：每节课的结果直接显示在课表行上（已签到 / 没签上 + 时间 + 原因）；每节结束还会在右下角弹一张小卡片。
- **每门课单独填签到地点**，不必所有课都用同一个地址。
- **提交优先带定位**：带经纬度和地址的接口连试 3 次，都失败才退回不带定位的方式。
- **失败原因诊断**：区分「程序坏了」和「这节课本来就没发起点名」——后者最常见。

## 下载

- `auto-checkin-setup-0.1.0.exe`（推荐）：安装版，装到当前用户目录，不需要管理员权限。
- 安装后从开始菜单或桌面打开「自动签到控制台」。
- 第一次打开会提示「还没配置完」，照着三步走即可。

## 已知限制

- **未做代码签名**：首次运行 Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。
- 依赖系统里**已安装的 Chrome**（不打包浏览器本体）。
- **只在 Windows 上测试过**。
- 不同课程的点名频率差异很大，某些课几周才点一次名——「盯着没抓到码」通常是正常现象，不是故障。

## 注意

本工具会代替你完成课堂签到，使用和传播都可能违反你所在学校的规定，后果自负。它仅供个人学习与技术研究。

你的账号密码只保存在本机 `data\credentials.json`，程序不会上传到任何地方。
